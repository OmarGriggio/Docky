# Brand assets

Docky's logo files (icon, horizontal logo, wordmark, in each color variant), kept here as the source originals - not served by the app.

The app only ever uses copies: `frontend/public/favicon.png` (browser tab icon and the nav-bar logo) is a copy of `docky-icone-vert-sur-blanc.png`. To use another one in the frontend, copy it into `frontend/public/` rather than referencing this folder.
